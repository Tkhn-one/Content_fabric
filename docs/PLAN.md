## 1. Идея продукта

Self-hosted веб-приложение, которое **полностью автоматически** производит вертикальные
короткие видео (Shorts / TikTok / Reels / VK Clips / Telegram) на заданную заказчиком тему:

1. Анализирует идеи и конкурентов по теме (LLM + поиск по YouTube).
2. Пишет сценарий (по шаблонам: факты, топ-5, история, вопрос-ответ…).
3. Генерирует озвучку (нейроголос или клон голоса) и при необходимости AI-аватара.
4. Монтирует видео: стоковые кадры или аватар, кинетические субтитры, фоновая музыка, водяной знак.
5. Публикует в выбранные соцсети **по расписанию** (N видео в день) или **вручную** одной кнопкой.
6. Ведёт журнал: Google Sheets (название, статус, ссылка, статистика) + архив в Google Drive.

**Модель продажи:** разовая лицензия (не подписка!), 3 тарифа, заказчик подключает **свои**
API-ключи (мы даём удобный мастер настройки и гайд). Дополнительно продаётся услуга
«установка и настройка под ключ».

## 2. Позиционирование

### Конкуренты
- **SaaS-сервисы** (FlowShorts $19–69/мес, Shortspilot $15–29/мес, ShortsVid $19+/мес):
  делают фейслесс-шортсы с автопостингом, но это **ежемесячная подписка**, каждая
  генерация стоит кредитов, данные уходят на чужой сервер.
- **Kwork-исполнители**: в основном делают «видео под заказ» (разовая генерация),
  а не систему с планировщиком, мультиплатформенной публикацией и журналом.

### Наши преимущества (это и есть текст продажи)
| Аргумент | Формулировка для карточки Kwork |
|---|---|
| Разовая оплата | «Покупаете один раз — пользуетесь вечно. SaaS с $19/мес окупается за 1–2 месяца» |
| Self-hosted | «Система живёт на вашем сервере, видео и данные не утекают в чужой сервис» |
| Свои ключи | «Никаких скрытых платежей: подключаете свои API, платите только за то, что используете» |
| Полный конвейер | «Идеи → сценарий → видео → публикация → отчёт — всё в одной панели, без ручной работы» |
| Расписание и ручной режим | «N видео в день по таймеру или одно нажатие кнопки» |
| Мультиплатформа | «YouTube Shorts, TikTok, Reels, VK, Telegram из одной панели» |
| White-label (Unlimited) | «Переименуйте систему под себя и перепродавайте — права на бренд ваши» |

### Кому продаём (ниши заказчиков)
- Авторы фейслесс-каналов (факты, мотивация, история, финансы, психология, крипта, кулинария).
- SMM-агентства (ведение каналов клиентов, мультиканальность — Unlimited).
- Арбитражники / инфлюенсеры, которым нужно «контент-сопло» без штата.
- Англоязычные ниши (мультиязычность — отдельная фишка).

## 4. Пайплайн генерации (один ролик)

```
Тема + настройки (панель)
        │
        ▼
[1] Исследование     — поиск трендов и конкурентов по теме (YouTube Data API + LLM)
        ▼
[2] Сценарий         — LLM по шаблону: хук (0–3 сек), основная часть, CTA
        │              (≈ 30–60 сек озвучки, таймкоды для субтитров)
        ▼
[3] Модерация (опц.) — человек смотрит сценарий/видео и жмёт «Опубликовать»
        ▼
[4] Озвучка          — TTS-провайдер (клонированный голос или нейроголос)
        ▼
[5] Визуал           — сток-кадры по ключевым словам ИЛИ AI-аватар по сценарию
        ▼
[6] Монтаж           — ffmpeg: вертикаль 9:16, субтитры, музыка, логотип
        ▼
[7] Публикация       — выбранные платформы (по расписанию или сразу)
        ▼
[8] Журнал           — Google Sheets (заголовок, статус, ссылки, статистика)
                       + копия видео в Google Drive
```

Каждый шаг — отдельный статус в панели (журнал заданий), при ошибке — ретрай и уведомление.

## 5. API-интеграции: стоимость и сложность получения

> **Принцип:** все ключи подключает **заказчик** через мастер настройки (с проверкой ключа).
> Разработчик не берёт комиссий и не требует оплаты подписок через себя.

| Сервис | Зачем | Стоимость | Сложность получения |
|---|---|---|---|
| **YouTube Data API v3** | поиск конкурентов, публикация Shorts, статистика | бесплатно (10 000 квот/день; загрузка ~100 ед. → десятки видео/день; расширение квоты бесплатно по заявке) | просто: Google Cloud → OAuth-клиент за 10 минут |
| **Google Sheets / Drive API** | журнал + архив | бесплатно (15 ГБ) | просто: service account |
| **Telegram Bot API** | публикация в Telegram | бесплатно | просто: @BotFather |
| **VK API** | публикация в VK Clips | бесплатно | просто: токен сообщества |
| **TikTok Content Posting API** | публикация в TikTok | бесплатно (до 25 видео/день на аккаунт) | средне: заявка на доступ к приложению, модерация 3–7 дней (нужны privacy policy, демо-видео) |
| **Instagram Graph API** | публикация в Reels | бесплатно | средне: Business/Creator-аккаунт + заявка и Live-режим приложения |
| **Pexels / Pixabay API** | стоковые кадры | бесплатно (ключ) | просто |
| **edge-tts** | базовые нейроголоса | бесплатно, без ключа | просто (встроен) |
| **ElevenLabs** | качественные голоса + **клон голоса** | платно, от ~$5/мес (голоса), clone от ~$22/мес | просто |
| **OpenAI / Claude / Gemini / YandexGPT** | сценарии, идеи, хештеги | платно от ~$1–5/мес на сценарии; у Gemini и YandexGPT есть бесплатные тарифы | просто |
| **HeyGen / D-ID** | AI-аватар | платно, от ~$5.9–29/мес | просто |

**Итого для заказчика:** минимальный бюджет на подписки ≈ **0 ₽/мес** (edge-tts + бесплатные
тарифы LLM + бесплатные API соцсетей), комфортный ≈ **$30–50/мес** (ElevenLabs + HeyGen + платный LLM).

## 6. Права, лицензии и защита

- **Код и все права на продукт принадлежат разработчику** (продавцу). Заказчик получает
  неисключительную лицензию на использование по своему тарифу.
- **Защита:** лицензионный ключ (Ed25519-подпись) с битовой маской функций и числом
  каналов; проверяется при запуске и в панели. Генератор ключей — только у продавца.
- **White-label (Unlimited):** заказчик может переименовать систему, сменить логотип и
  перепродавать её как свою (лицензионные ключи он выпускает сам, мы даём панель).
- Перепродажа на тарифах Basic/Pro запрещена лицензией (только личное использование).
- Ограничение «подписка на ИИ»: заказчик обязан использовать свои ключи; продавец
  не несёт ответственности за расходы по чужим ключам.

## 9. Идеи на будущее (бустеры v2, после первых продаж)

1. **Reels из длинных видео** — нарезка ютуб-видео на шортсы с ИИ-перемонтажом.
2. **AI-музыка** — генерация треков под ролик (Suno/окт. аналоги).
3. **Собственная микроплатежная витрина** — продажа лицензий без Kwork (Telegram-бот или лендинг).
4. **Импорт тем из CSV/Sheets** — массовое производство по списку тем.
5. **Интеграция с календарём** — автовыбор дат по статистике канала (когда аудитория активна).
6. **A/B заголовки и обложки** — публикация вариантов и авто-замена слабых.
7. **Мульти-голосовые диалоги** — формат «фейк-чат»/Reddit stories (очень виральный формат).
8. **API для внешних систем** — чтобы заказчик мог дёргать фабрику из своих скриптов.
9. **Авто-рассылка отчёта в Telegram** — «сегодня опубликовано 3 видео, ссылки».
10. **Мультирегиональная озвучка** — один ролик → 5 языков → 5 версий (сильная фишка для экспатов).

## 10. Риски и как их закрываем

| Риск | Решение |
|---|---|
| TikTok/IG не одобрят приложение заказчику | Гайд с правильной формулировкой заявки + privacy-policy шаблон; платформы подключаем модульно (работают YT/TG/VK без одобрений) |
| Смена API/лимитов у провайдеров | Слой абстракций: каждый провайдер — плагин, замена за 1–2 дня |
| Пиратство лицензии | Ed25519-ключи, в Unlimited — свой генератор у перепродавца; онлайн-проверка опциональна |
| Конкуренты скопируют идею | Скорость: продаём Basic уже после этапа 2; постоянные апгрейды |
| Заказчик «не технарь» | Услуга «установка под ключ» + PDF-гайд + видеогайд |
