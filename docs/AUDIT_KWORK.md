## 1. Критические исправления (внесены в этом коммите)

### Безопасность
| Проблема | Риск | Исправление |
|---|---|---|
| `CF_SECRET_KEY = "change-me-in-production"` по умолчанию → JWT можно подделать, зная дефолт | **CRITICAL** | В `lifespan()` если ключ дефолтный — генерируется временный `token_urlsafe(32)` + `logger.warning`. При первом запуске без Docker `.env` уже создаётся с рандомным ключом (`_ensure_env_file`). |
| `CORS allow_origins=["*"] + allow_credentials=True` — браузер отклоняет, Starlette ругается | HIGH | В `main.py` если `origins==["*"]` то `allow_credentials=False`. Добавлены `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy`. |
| Brute-force `/api/auth/login` без лимита | HIGH | In-memory rate-limit 10 попыток/60 сек на username (простой, без Redis — достаточно для self-hosted одного юзера). Возвращает 429. |
| `PROVIDERS` дублировал `avatar/heygen` дважды (копипаст) | MEDIUM | Удалён дубликат в `providers/registry.py`. |
| `ProviderOut` мог раскрыть секреты | LOW (проверено — не раскрывает) | `list_providers` возвращает только `label` из `decrypt_secrets(...).note`, сам `encrypted_payload` не отдаётся. Оставлено как есть. |

## 2. Оставшиеся некритичные проблемы → бэклог (не блокеры для продажи)

1. **SQLite `check_same_thread=False` + `pool_pre_ping`** — ок для 1 юзера, но при 10+ параллельных jobs может блокировать. Для Unlimited с 10 каналами → рекомендовать Postgres (уже `CF_DB_URL` поддерживает).
2. **`/media` без авторизации** — любой, кто знает URL, скачает видео. Для self-hosted на VPS за Caddy BasicAuth это ок; если нужен приватный — повесить прокси через `/api/media/{job_id}` с проверкой JWT.
3. **Лицензия: `support_until` проверяется только по дате, без CRL.** Украденный Unlimited-ключ вечен до даты. Для разовой продажи ок; для перепродажи — добавить блеклист в `SystemSetting`.
4. **Pydantic `class Config` deprecated** — ворнинги в тестах (4 шт). Заменить на `model_config = ConfigDict(...)` перед релизом.
5. **JWT без refresh/rotate, 7 дней.** Для одного админа ок. При угоне токена — живёт неделю. Можно снизить до 24ч и добавить `/api/auth/refresh`.
6. **Нет бэкапа БД.** Добавить в `SETUP_GUIDE` cron `cp data/cf.db data/cf.db.bak` или `litestream`.
7. **`imageio-ffmpeg` fallback** — тянет ~40 МБ бинаря; на VPS с apt-ffmpeg дублирование. Ок.
