# Руководство по настройке — что требуется от заказчика

> Этот документ — ваша часть работы. Всё, что можно сделать без внешних ключей,
> я уже реализовал и протестировал. Здесь — **точные шаги**, что нужно настроить
> у себя, чтобы включить реальные функции.
> Правило: **все ключи подключаете вы через панель** (Подключения → Мастер API).
> Ключи хранятся зашифрованными на вашем сервере.

Время прохождения всех шагов: ~30–40 минут (разово).

---

## Шаг 0. Проверка локального запуска (10 мин)

Убедитесь, что система у вас крутится (на сервере или локально):

```bash
# Вариант A — Docker (сервер)
cd deploy
cp .env.example .env        # поменяйте CF_SECRET_KEY
docker compose up -d --build
# откройте http://<IP> → логин admin / пароль из .env

# Вариант B — dev (локально, нужен python 3.11+ и ffmpeg)
cd backend
python -m venv .venv
.venv/bin/pip install -r requirements.txt
CF_SECRET_KEY=dev ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
# → http://localhost:8000
```

**Проверка 0.1** — создайте тему (например «Факты о космосе»), нажмите «Сгенерировать сейчас».
Должно получиться задание со статусом «Модерация» и сгенерированное видео.
Если в деталях задания `озвучка пропущена: Cannot connect...` — на сервере нет доступа к
`speech.platform.bing.com` (нужно открыть исходящий 443) или у ffmpeg нет libass.

## Шаг 1. Pexels — стоковые кадры (2 мин, бесплатно)

1. Откройте https://www.pexels.com/api/ → **Join / Get Started** (регистрация по email).
2. Создайте ключ: **Your API Key** → скопируйте строку вида `AbCdef...`.
3. В панели: **Подключения → Тип «stock» → Провайдер pexels** → вставьте ключ в `api_key` → Сохранить.

Теперь фоны роликов — реальные фото по теме (не градиенты). Без ключа система работает
на градиентах — это нормально для демо.

## Шаг 2. Telegram — публикация в канал (3 мин, бесплатно)

1. В Telegram: напишите **@BotFather** → `/newbot` → имя бота → имя-username → получите
   **bot_token** вида `123456789:AA...`.
2. Напишите вашему боту любое сообщение (`/start`).
3. Получите chat_id:
   ```bash
   cd tools/oauth
   pip install httpx            # если ещё нет
   python telegram_chat.py --token 123456789:AA...
   ```
   Скрипт напечатает `chat_id` (для канала — id с минусом, для чата — обычное число).
4. В панели: **Подключения → publish → telegram** → `bot_token` + `chat_id` → Сохранить.

## Шаг 3. YouTube Shorts — публикация и статистика (15 мин, бесплатно)

Это самый длинный шаг, делайте внимательно.

### 3.1. Проект Google Cloud
1. https://console.cloud.google.com → создать проект (например `content-factory`).
2. **APIs & Services → Library** → найти **YouTube Data API v3** → **Enable**.

### 3.2. OAuth consent screen
3. **APIs & Services → OAuth consent screen** → выбрать **External** → Create.
4. App name: `Content Factory`, ваш email → Save.
5. В разделе **Audience → Test users → Add users** → добавьте email своего канала (обязательно!).
   (В production-режиме Google запросит верификацию — для личного канала хватает Test-режима:
   100 тестовых пользователей, 7 дней жизни токенов, но refresh-токен не протухает.)

### 3.3. Клиент
6. **Credentials → Create Credentials → OAuth client ID → Desktop app** → Create.
7. Скопируйте **Client ID** и **Client Secret**.

### 3.4. Получить refresh_token (одноразово)
8. Запустите (на своей машине с Python):
   ```bash
   pip install httpx
   cd tools/oauth
   python youtube_oauth.py --client-id <CLIENT_ID> --client-secret <CLIENT_SECRET>
   ```
9. Откройте ссылку из консоли, войдите **каналом, куда будете публиковать**, нажмите Allow.
10. Скрипт напечатает `refresh_token` и `channel_id`.
    (Если браузер не открыл localhost — запустите с флагом `--manual` и вставьте code.)

### 3.5. Внести в панель
11. **Подключения → publish → youtube** → заполните: `client_id`, `client_secret`,
    `refresh_token`, `channel_id` → Сохранить.

> Важно: ключи принадлежат вашему Google-проекту. Квоты бесплатные (10 000 ед./день,
> загрузка ~100 ед. → десятки роликов в день).

## Шаг 4. Google Sheets + Drive — журнал и архив (10 мин, бесплатно)

### 4.1. Сервисный аккаунт
1. В том же проекте Google Cloud: **APIs & Services → Library** → включить
   **Google Sheets API** и **Google Drive API**.
2. **Credentials → Create credentials → Service account** → имя `cf-service` → Done.
3. В списке аккаунтов → нажмите на `cf-service` → вкладка **Keys → Add key → Create new key →
   JSON** → скачается файл `*.json` (это `service_account_json`, содержимое файла целиком).

### 4.2. Подготовить таблицу и папку
4. Создайте **Google-таблицу** (например «Content Factory»), переименуйте первый лист в `Журнал`,
   добавьте заголовки в строку 1: `Дата | Тема | Ниша | Заголовок | Платформы | Статус | Ссылка`.
   Скопируйте **ID таблицы** из URL (часть между `/d/` и `/edit`).
5. Поделитесь таблицей с email сервисного аккаунта (в правом верхнем углу таблицы «Доступ» →
   вставьте email из JSON, поле `client_email`) — роль **Редактор**.
6. Создайте **папку Google Drive** для архива роликов → скопируйте **ID папки** из URL.
   (Делать это нужно с того же аккаунта, что владеет проектом; папку тоже поделите с `client_email`.)

### 4.3. Внести в панель
7. **Подключения → storage → google_sheets** → `service_account_json` (вставьте ВЕСЬ JSON одной строкой)
   + `spreadsheet_id` → Сохранить.
8. **Подключения → storage → google_drive** → `service_account_json` + `folder_id` → Сохранить.

## Шаг 5. Фоновая музыка (2 мин, по желанию)

1. Создайте папку `data/media/music/` рядом с приложением (в Docker: `docker compose exec app mkdir -p /app/data/media/music`).
2. Положите туда 1–5 треков `.mp3` (royalty-free: YouTube Audio Library, Pixabay Music, Free Music Archive).
3. Система сама выберет случайный трек и **приглушит его под голосом** (ducking).

## Шаг 6 (Pro). Клон голоса и AI-аватар — появятся на этапе 4

Заглушки уже стоят. Когда дойдём до этапа 4, потребуется (опционально):
- **ElevenLabs** — https://elevenlabs.io → API key (+ `voice_id`; клон голоса — в разделе Voice Lab).
- **HeyGen** — https://heygen.com → API key (+ `avatar_id`) — для говорящего аватара.
